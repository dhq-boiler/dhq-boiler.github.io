  • Unofficial VS MCP
    • Visual Studio用のModel Context Protocol (MCP)サーバーです。Claude CodeなどのAIエージェントからVisual Studioのデバッグ、ビルド、エディタ操作、UIオートメーションなどの機能を制御できます。106個のツールを16カテゴリにわたって提供しています。 Visual Studio Marketplace
    主な機能：
    • デバッグ機能（ブレークポイント設定、ステップ実行、コールスタック表示）
    • ビルド機能（ソリューション/プロジェクトのビルド、クリーン、リビルド）
    • エディタ機能（ファイルの開閉、読み書き、コード検索・移動）
    • UIオートメーション（スクリーンショット、UI要素の検査、クリック操作）
    • Webブラウザ制御（Chrome/Edge/Firefoxの自動操作）
    • テスト実行・NuGet管理
