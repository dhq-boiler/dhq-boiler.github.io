01 About

プロフィールと得意領域

C#/WPF による Windows デスクトップアプリ開発を 8 年以上、個人でも業務でも継続しています。

近年は Visual Studio や Claude Code などの開発者ツール × 生成AI 連携（Model Context Protocol / エージェント統合）にも軸を広げており、 自作の VS 拡張 MCP サーバー Unofficial VS MCP は Visual Studio Marketplace で累計 1,000+ install、★5.0 を獲得しています。 AI 協調型の UML クラス図エディタ Kata（Roslyn + 自作 C++/CLI パーサー、Fowler リファクタリング／コードスメル、Claude / Codex 連携）も v1.0 をリリース済み。

Microsoft Store では STREAM DIRECTOR、 boiler's Graphics、 Kakeibo の 3 本を配布中（うち 2 本は有償販売実績あり）。 C++/CLI ネイティブ層、SaaS 課金基盤、難読化パイプライン、SourceGenerator、UI Automation まで幅広く実装しています。
